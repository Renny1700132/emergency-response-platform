# 每日工作报告 Skill

## 1. 适用范围与触发条件

仅当用户明确要求撰写、重写或补录每日工作日志、日报、每日总结时使用。本 Skill 只负责恢复可核验的每日工作事实，不把最终成果倒推成未经记录的过程，也不记录隐藏思维、系统消息或工具内部状态。

固定角色映射：

- 何思源 = A，项目经理 PM / 第一关最终质量负责人；
- 严宇 = B，技术负责人 / 架构师；
- 任俊强 = C，需求 / 质量 / 合规负责人。

## 2. 强制证据读取顺序

生成某人某日日报时，必须先完整读取对应的 `logs/prompts/YYYY-MM-DD-A|B|C.md`。若该日期沿用早期共享日志，还须读取 `logs/prompts/YYYY-MM-DD.md`，但只能采用其中明确标识为该成员执行的记录。

随后按与当天任务相关的最小范围读取：

1. `logs/reviews/` 中对应 Review、复验和关闭记录；
2. `logs/meetings/`、`logs/failures/` 中可归属到该成员、该日期的证据；
3. `control/issues.md`、`control/change_log.md`、`tasks.md` 中的状态、裁决和版本事件；
4. `git log --since <当日00:00> --until <次日00:00>`；
5. 对应提交的文件清单与 diff；
6. 当日实际形成或修改的最终文件。

证据解释规则：

- Prompt 证明“当天被要求做什么”；
- Review、Git 和最终文件证明“实际形成了什么、是否返工、是否通过”；
- 只有两类证据能够互相印证时，才写成完成；
- Prompt 要求但无结果证据的事项，只能写成“已提出/待核验”，不得写成完成；
- 后续日期形成的结果不得倒填为当天结果；
- 不复制 Prompt 全文，只提炼任务背景、范围和验收要求；
- 没有证据的会议、人物动作、时间、问题、决策、修改和提交坚决不写；
- 当天确实无该成员记录时，写明“当日未检索到该成员可核验的工作记录。”

## 3. 篇幅与粒度

正常有工作记录的一天，每人建议约 600～1200 中文字；工作量特别大时允许更长。不得用“完成 G1-xx”“完成技术标整合、跨文档整改”等一句话替代过程。

每项实际工作应尽量回答：为什么要做、输入是什么、执行了什么、发现什么问题、如何分析或修改、是否经历 Review、Review 的关键意见、如何处置、最终形成什么结果。若某一环节没有证据，应直接省略或标注未检索到，不得补造。

## 4. 固定输出结构

```markdown
# 每日工作报告

- 日期：YYYY-MM-DD
- 姓名：实名
- 项目角色：角色
- 补录说明：根据当日 Prompt、Review、Git 与成果文件补录；不含无法核验的过程。

## 1. 今日工作概览

用 1～2 段说明当天任务背景、目标，以及它在第一关中的位置。

## 2. 具体工作过程

### G1-xx 任务名称

- 说明输入、核查对象、实际动作、发现的问题、处置方法、Review 与结果。
- 工作量大时按真实任务继续增加小节，不合并成一句话。

## 3. 主要成果与文件

- 明确列出文件路径、文档版本、Review 报告、图表、Prompt/治理记录及可核验 commit。

## 4. 关键问题、决策与解决过程

- 记录真正有价值且有证据的问题，例如需求解释冲突、reference 差异、Word 重建失败、插图缺口、Reviewer 驳回、Git 冲突或 AI 输出错误，并说明解决结果。

## 5. Review 与质量控制

- 写明 Reviewer、检查重点、BLOCKING/MAJOR/MINOR 结论、返工与最终状态；无 Review 证据时明确写“当日未检索到独立 Review 记录”。

## 6. 当日结论与下一步

总结当天已闭环事项；下一步只能写任务台账、Review 或变更记录中有证据支持的内容。
```

## 5. 无记录日写法

无记录日仍使用固定标题和身份字段。在“今日工作概览”中写唯一结论“当日未检索到该成员可核验的工作记录。”其余章节统一写“无可核验记录”，不得为了凑字数虚构工作。600～1200 字建议不适用于无记录日。

## 6. 交付前自检

- [ ] 已完整读取对应角色 Prompt 日志；
- [ ] 完成结论均有 Review、Git 或成果文件印证；
- [ ] 正常工作日达到过程级粒度；
- [ ] 明确列出真实文件、版本、Review 与 commit（如可核验）；
- [ ] 没有复制 Prompt 全文；
- [ ] 没有隐藏思维或虚构过程；
- [ ] 无记录日使用规定原句；
- [ ] 姓名与角色映射正确。
