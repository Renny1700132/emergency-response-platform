# 每日工作报告 Skill

## 触发条件

仅当用户明确要求“撰写每日日志 / 每日总结 / 工作日报 / 补全某日工作报告”时调用。

## 角色映射

- 何思源 → A
- 严宇 → B
- 任俊强 → C

## 数据与写法

优先读取对应日期的 `logs/prompts/YYYY-MM-DD-A.md`、`-B.md`、`-C.md`；可结合当日 `logs/reviews/`、`tasks.md` 与 Git commit 核验结果，但不得以后来的结果反向补造当日工作。

每份日报简洁包含：日期、姓名、项目角色、今日工作内容、主要产出或完成事项、Review / 问题处理情况，以及仅在有证据时写的未完成事项或下一步。

## 纪律

- 仅总结可由日志证明的工作，不复制完整 Prompt，不写隐藏思维过程。
- 不补造会议、修改、提交或成果。
- 无对应成员 Prompt/工作证据时，明确写：`当日未检索到该成员可核验的工作记录。`
- 历史补写必须注明“根据 Prompt/Git 日志补录”，不得伪造成当日实时撰写。
