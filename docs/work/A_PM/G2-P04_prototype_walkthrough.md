## 6. 第三关设计输入

1. 把原型的事件、任务、关闭材料、演练、打卡告警/通知、盘点快照与差异转化为领域模型、状态机、审计事件和接口契约；不得直接把 localStorage 结构当作数据库设计。
2. 明确视频、定位、消息、门禁、IoT 与中台的真实接口、授权、失败重试、降级和验收环境；原型 Mock 的展示与状态仅用于发现交互问题。
3. 为 39 条 FR、全部 ★ 条款和所有 AC 补足设计、测试用例、测试数据和证据链；未出现在原型闭环中的条目仍须设计与验证。
4. 在正式设计中定义权限边界、附件处理、日志保留、数据分类、异常恢复、性能测量和部署架构；这些不属于原型完成结论。

原型达到 G2-P04 的最小验证目标：主要菜单可进入，P1—P5 无死链接或状态中断，五条闭环均有 Mock 级走查证据，且边界表述未越过真实项目验收。建议将 G2-P04 提交 B、C 复核；在其完成独立技术与符合性复核前，任务状态保持 `REVIEW`。
