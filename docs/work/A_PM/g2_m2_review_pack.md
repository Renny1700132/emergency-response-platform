## 5 ISSUE-G3-01-001 的显式处置

`ISSUE-G3-01-001` 继续保持 OPEN。仓库仍缺少视频和统一消息通道的真实环境/账号前置、接口版本或字段清单、脱敏请求响应/回执、失败场景及连通结论；Mock、规格文本、原型演示和需求追踪均不能替代这些证据。

本轮候选冻结允许 G3 使用抽象外部端口和待确认字段开展逻辑设计，但明确排除以下结论：

1. 不冻结视频/消息的真实外部接口契约、错误码、认证和超时预算；
2. 不声明≥20路、≥99%、首帧≤3秒或其他现场指标已经验证；
3. 不将 Mock 回执或原型状态视为真实通道成功；
4. `ISSUE-G3-01-001` 继续阻断 G3-06 外部接口冻结和 G3-10/M3最终冻结，直至真实证据齐备或取得书面替代/延期裁决。
