## 3 MVP 范围边界

### 3.1 MVP 内

五个 MVP 优先形成“预案—事件—指挥—现场执行—评估改进”可验证闭环，并同步前置外部接口、性能和安全验证；MVP-2 纳入 FR-02.4 以闭合物资站点一张图，MVP-3 纳入 FR-03.3、FR-03.4 作为 FR-08.6 移动物资盘点的直接数据与流程依赖。待验证事项不表述为已验收。

### 3.2 非 MVP、但仍属于本期项目范围

FR-01.4、FR-03.1、FR-03.2、FR-07.1、FR-07.2、FR-07.3、FR-07.4、FR-07.5、FR-08.3、FR-09.1，以及相互依赖的配置、数据初始化、文档、培训、试运行和服务，仍须按项目计划实施、测试和验收。全量 39 条 FR 的用例、性能实测和验收证据不得因 MVP 分期而省略。

### 3.3 明确不属于本项目

既有视频、入侵报警、出入口控制、消防报警、广播、客流统计等系统本体建设或改造；相关硬件采购；机房/服务器/网络采购；政府应急平台专线工程；馆内地图重新测绘、从零三维建模或基础地图版权采购；独立原生 Android/iOS APP；正式第三方等保测评采购。范围外不免除本项目的软件接口适配、联调、容错、降级、验证和交付责任。

## 4 非功能验收基线、接口与澄清口径

全部 FR 建立测试用例、功能验收通过率 100%；PE-01—PE-12在部署环境逐项实测且全部达标；视频、信息发布、物联网、中台完成端到端联动；至少一次模拟突发事件全流程联合演练；高危漏洞清零；非乙方人员按手册在干净环境独立部署且一次成功。

- DEC-001：既有视频负责录像产生、存储及不低于30天保存；本项目负责接入、实时调阅、回放和验证，不新建存储。
- DEC-002：甲方提供定位基础设施、源数据和验收条件；本项目负责接口、关联、楼层/坐标映射、展示和刷新，不降低源精度。
- DEC-003：门禁按“应支持”执行，经授权确认、服从安全联锁，失败告警并人工降级。
- DEC-004：甲方提供统一消息通道及条件；本项目负责调用、编排、并行、重试、回执、留痕、降级和正常通道验证。
- DEC-005：复用统一中台通用能力，本项目只做应急业务适配。
- DEC-006：甲方提供合法地图/服务，本项目负责加载、兼容、点位、坐标拾取和叠加。
- DEC-007：采用 H5 嵌入既有智慧管理 APP，不另做原生 APP。
- DEC-008：甲方提供私有环境和基础资源；本项目完成软件部署和容器化交付。
- DEC-009：甲方提供源数据并确认业务正确性；本项目完成模板、映射、清洗、导入与技术校验。
- DEC-010：甲方提供接口资料、账号、环境和窗口；本项目逐接口适配、联调、容错、降级、验证，视频和消息 M2 前连通。
- DEC-011：本项目负责应用侧相关要求及高危清零；甲方负责最终定级/备案及测评组织。
- DEC-012：项目和甲方使用课程匿名名称。
