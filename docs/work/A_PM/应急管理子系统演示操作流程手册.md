# 某自然博物馆智能运营中心建设项目 应急管理子系统演示操作流程手册

- 文档状态：V0.9 汇报候选
- 适用版本：`codex/g4-09-sprint2-frontend`，演示功能基线 `a8daed5`
- 使用对象：项目汇报人、现场演示操作人
- 使用边界：演示数据仅用于汇报，不作为正式验收证据；正式模式仍保留宿主令牌鉴权边界。

## 快速入口

- Web 总览：[http://127.0.0.1:5174/web/overview](http://127.0.0.1:5174/web/overview)
- Web 事件：[http://127.0.0.1:5174/web/incidents](http://127.0.0.1:5174/web/incidents)
- Web 任务：[http://127.0.0.1:5174/web/tasks](http://127.0.0.1:5174/web/tasks)
- H5 任务：[http://127.0.0.1:5174/h5/tasks](http://127.0.0.1:5174/h5/tasks)

## 1 演示目标与主线

在 8—10 分钟内展示“态势总览—事件上报—指挥核实—启动响应—任务下发—H5 接收—进度反馈—总览实时更新”的完整闭环，并快速覆盖预案、资源、演练、值班、知识库、综合安防和外部系统对接入口。

## 2 演示前准备

1. 在项目根目录执行 `npm run dev --prefix frontend`。
2. 终端出现 `Local: http://localhost:5174/` 后，打开 `http://127.0.0.1:5174/web/overview`。
3. 确认未跳转至 `auth-required`，顶部显示“演示数据 · 实时互通”。
4. 新建第二个标签页，打开 `http://127.0.0.1:5174/h5/tasks`。
5. Web 标签页保留在总览；H5 标签页保留在任务页。
6. 如果提示 5174 被占用，在旧前端终端按 `Ctrl+C` 后重新启动。

## 3 完整点击流程

操作时严格按本章顺序执行。除步骤明确要求外，不刷新浏览器，否则会中断“无需刷新实时互通”的展示效果。

### 3.1 总览开场

1. 在 Web 标签页点击左侧“态势总览”。
2. 指出顶部“演示数据 · 实时互通”和“演示角色”下拉框。
3. 依次指向进行中事件、处置任务、在线设备、今日值守四张指标卡。
4. 向下展示 GIS、当前活跃事件、任务进度和系统健康。

### 3.2 上报事件

1. 点击左侧“事件管理”。
2. 点击页面右上“上报事件”。
3. 事件类型代码输入 `FIRE`。
4. 发生时间保持当前值。
5. 标题输入“东展厅疑似烟雾告警”。
6. 描述输入“巡检人员发现展柜附近出现轻微烟雾，请求核实。”
7. 点击“提交上报”。
8. 确认出现“事件已提交”，列表首项为新事件且状态为 `PENDING_VERIFY`。
9. 点击左侧“态势总览”，确认进行中事件数量和最近动态更新。

### 3.3 核实事件并启动响应

1. 点击顶部“演示角色”下拉框，选择“应急指挥员”。
2. 点击左侧“事件管理”。
3. 找到“东展厅疑似烟雾告警”，点击“核实 / 启动处置”。
4. 核实结论选择“确认事件”。
5. 核实说明输入“现场确认存在烟雾，需要立即处置”。
6. 点击“提交核实”，确认状态更新。
7. 预案版本 ID 输入 `PLAN-FIRE-2026-V3`。
8. 启动说明输入“启动展厅火情专项预案”。
9. 点击“启动预案”，确认事件状态为 `RESPONDING`。

### 3.4 创建临时任务

1. 点击左侧“应急任务”。
2. 点击页面右上“临时任务”。
3. 任务名称输入“疏散东展厅游客”。
4. 执行人输入“安保一组”。
5. 截止时间选择当前时间之后 30 分钟。
6. 说明输入“引导游客从东侧安全通道有序撤离。”
7. 点击“创建临时任务”。
8. 确认出现“临时任务已创建”，列表首项出现新任务，状态为 `PENDING`。

### 3.5 H5 现场安保接收与反馈

1. 切换到 H5 标签页。
2. 如果当前不在任务页，点击底部“任务”。
3. 返回 Web 标签页，在顶部角色下拉框选择“现场安保员”；再切回 H5 标签页，确认角色显示同步。
4. 找到刚创建的“疏散东展厅游客”。
5. 点击“接收任务”，确认状态为 `ACKNOWLEDGED`。
6. 点击“提交反馈”展开表单。
7. 反馈内容输入“安保人员已到位，疏散正在进行”。
8. 进度输入 `80`。
9. 点击“提交反馈”，确认状态为 `IN_PROGRESS`、进度为 `80%`。

### 3.6 验证 Web H5 实时互通

1. 切回 Web 标签页，不执行浏览器刷新。
2. 点击左侧“应急任务”，确认同一任务显示 `80%`。
3. 点击左侧“态势总览”。
4. 确认任务进度条为 `80%`，最近动态显示“现场安保员”提交的反馈，实时版本号增加。
5. 说明 Web、H5 与多个标签页通过同一演示会话状态实时互通。

### 3.7 物资保障协同

1. 顶部角色下拉框选择“物资保障员”。
2. 点击左侧“应急任务”。
3. 找到“准备临时警戒物资”。
4. 点击“接收任务”。
5. 点击“提交反馈”。
6. 反馈内容输入“警戒带、应急灯和扩音设备已完成配备”。
7. 进度输入 `60`，点击“提交反馈”。
8. 点击左侧“人员与物资”，展示人员、物资站点和保障状态。
9. 返回“态势总览”，确认最近动态和任务进度同步。

### 3.8 指挥态势与综合安防

1. 点击左侧“指挥态势”。
2. 展示综合安防地图、事件点位和人员位置。
3. 点击视频区域的调阅入口，说明实时视频与异常状态可关联事件。
4. 展示门禁状态和信息发布区域。
5. 仅讲解门禁安全联锁、失败回执和人工降级边界，不在汇报现场执行高风险控制。

### 3.9 其他核心模块巡览

1. 点击“应急预案”，展示已发布预案、待审核版本和风险类型覆盖。
2. 点击“应急演练”，展示年度计划、本月演练和整改事项。
3. 点击“值班值守”，展示排班、到岗和交接信息。
4. 点击“知识库”，展示知识分类、处置规范与检索入口。
5. 点击“外部对接”，展示消防、视频、门禁、物联网、客流、中台等 8 类接口状态。
6. 点击顶部“H5”，依次指向底部事件、任务、演练、打卡、盘点、知识六个入口。

## 4 收尾话术

本次演示覆盖“发现—上报—核实—响应—任务—反馈—态势更新”的完整业务闭环，同时展示 Web/H5 多角色实时协同，以及预案、资源、演练、值班、知识和外部系统等核心功能。当前为汇报级演示候选，演示数据不作为正式验收证据。

## 5 现场异常处理

| 异常 | 处理 |
| --- | --- |
| 5174 端口被占用 | 在旧前端终端按 `Ctrl+C`，重新执行启动命令 |
| 进入认证提示页 | 确认使用 `npm run dev --prefix frontend`，不要使用 `dev:formal` |
| H5 未同步 | 确认两个标签页同源且均为 127.0.0.1:5174，重新打开 H5 标签页 |
| 操作后页面未变化 | 先切换到其他菜单再返回；仍异常时重启演示服务并重新走流程 |
| 数据已被前一次演示修改 | 重启演示服务并关闭旧标签页，重新打开 Web 与 H5 标签页 |

- [ ] 顶部角色下拉框可切换三种角色。
- [ ] 事件上报、核实、启动响应可执行。
- [ ] 任务创建、接收、反馈可执行。
- [ ] Web/H5 不刷新即可同步。
