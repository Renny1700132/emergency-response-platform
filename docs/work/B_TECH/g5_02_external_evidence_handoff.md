## 1 ISSUE-G5-02-001｜甲方真实外部系统

甲方或教师需一次性提供：验收环境地址、受控测试账号/令牌、合法测试数据、允许的测试窗口、接口限流和安全约束、视频点位、定位源、GIS 图层、消息通道、安防/信息发布测试对象。任何真实密钥只在受控环境注入，不写入仓库或日志。

| 验证项 | 必需原始证据 | 判定 |
|---|---|---|
| PE-02 告警接入 | 每请求发送时间、接收时间、状态、traceId；至少覆盖正常/无权/超时失败 | 刷新/接入≤2秒，失败留痕且不丢失源数据 |
| PE-04 消息通道 | ≥20 路并发的逐路请求、回执、重试、最终状态和 traceId | 正常验收通道到达率≥99%，不得以模拟通道替代 |
| PE-05 定位 | 源坐标、源精度、采集时间、平台展示时间和关联对象 | 刷新≤2秒且平台不降低源精度 |
| PE-06 视频 | 直播首帧、历史回放、录像时间范围、外部引用和 traceId | 可调阅回放；≥30天保存由既有视频系统证明 |
| PE-08 GIS | 地图加载、图层/点位叠加、操作耗时、错误与降级 | 使用甲方地图服务完成场景操作并保留耗时 |
| PE-10 安防/发布 | 真实回执、状态刷新、超时失败与人工降级 | 满足受控刷新时限；门禁失败不得自动重放 |

执行后将脱敏原始记录写入新的受控证据文件，更新 `environment-readiness.json`，由 C 独立复验；在取得上述输入前保持 `OPEN / ENVIRONMENT_REQUIRED`。
