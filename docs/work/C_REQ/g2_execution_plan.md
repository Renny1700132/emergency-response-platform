## 目标与固定门禁

第二关形成一套给人阅读的 SRS 与一套机器可读的 spec.md。两份规格以同一编号、同一范围和同一验收条件保持双向一致。M2 评审前必须同时满足：

1. 每条功能需求都有 Given/When/Then 验收标准；
2. Must 与 MVP 边界一致；
3. AI 反向澄清不少于 10 条，且每条有人工裁决或驳回理由；
4. RTM 从需求到验收标准无断链，并预留设计和测试挂接列；
5. SRS 与 spec.md 抽查任一需求均不矛盾。
