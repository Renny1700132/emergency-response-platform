# G1-04 技术问题与外部依赖清单

- 任务：G1-04 技术方案
- 主责：B
- 复核：A
- 版本：V0.1
- 状态：基线前技术准备
- 权威来源：`docs/用户需求书-03-应急管理子系统.docx`

## 1. 使用说明

本清单用于在总体架构定稿前确认外部能力、部署条件和验收环境。问题按“需求依据—待确认问题—技术影响—建议证据”组织。当前问题不替代 C 的需求解析和澄清记录；涉及条款解释或关键数字时，由 C 核对原文并纳入 G1-01/G1-02 或 G1-05。

## 2. 阻塞总体设计的问题

### TQ-001 统一身份认证与组织机构同步

- 需求依据：FR-11.2，第 8.2 节。
- 待确认问题：统一业务运行中台提供何种单点登录协议、令牌格式、组织机构数据模型、同步方式和账号停用机制？
- 技术影响：登录流程、用户主键、角色映射、数据权限和接口网关设计。
- 建议证据：接口规范、测试账号、组织机构样例和错误码说明。

### TQ-002 统一消息推送能力

- 需求依据：第 3.3、4.3、4.4 节，FR-08.2、FR-11.2。
- 待确认问题：平台可用的 APP 推送和短信通道、调用配额、批量接口、到达回执、失败码、重试责任边界分别是什么？
- 技术影响：消息适配器、并行发送、回执汇聚、重试和补偿策略。
- 建议证据：接口文档、通道服务级别说明、联调环境和回执样例。

### TQ-003 人员定位数据来源

- 需求依据：FR-02.2、PE-05。
- 待确认问题：人员定位由哪个既有系统或设备提供？是否包含楼栋、楼层、坐标系、时间戳、精度标识和在线状态？
- 技术影响：一张图刷新、楼层匹配、轨迹可信度和性能验证。定位基站等硬件不在本项目采购范围，需明确招标人提供条件。
- 建议证据：定位接口、样例数据、更新频率说明和现场精度测试报告。

### TQ-004 场馆地图和空间数据

- 需求依据：第 4.3、6.1 节。
- 待确认问题：现有二维或三维地图的数据格式、坐标系、楼层编码、服务协议、版权和更新责任是什么？
- 技术影响：地图引擎适配、点位拾取、地理围栏、人员和物资图层叠加。
- 建议证据：地图数据样本、坐标转换规则和地图服务访问说明。

### TQ-005 视频监控平台接入

- 需求依据：FR-02.3、FR-11.3，第 8.1 节。
- 待确认问题：现有平台是否完整支持 GB/T 28181，平台级联方式、设备目录规模、鉴权方式、实时流格式、录像检索和播放能力分别是什么？
- 技术影响：视频接入适配器、浏览器播放链路、首帧性能和故障降级。
- 建议证据：平台厂商及版本、协议说明、设备目录样例和联调账号。

### TQ-006 告警和物联网数据接入

- 需求依据：FR-11.1，第 3.3、8.2 节。
- 待确认问题：告警采用推送还是轮询，事件唯一标识、告警级别、区域编码、恢复消息、断点位置和补传窗口如何定义？
- 技术影响：告警去重、乱序处理、断连补传、告警转事件规则和审计。
- 建议证据：接口契约、告警样例、重放规则和联调环境。

### TQ-007 信息发布和出入口控制联动

- 需求依据：FR-11.3，第 3.3、8.1 节。
- 待确认问题：发布、撤销及门禁开启指令是否支持结果回执？哪些动作需要人工二次确认，联动失败时由谁处置？
- 技术影响：高风险指令确认、幂等控制、执行状态跟踪和人工降级流程。
- 建议证据：指令接口、权限矩阵、回执定义和现场联动规程。

### TQ-008 私有部署资源

- 需求依据：第 4.2、6.2、7.5、7.8 节。
- 待确认问题：招标人可提供的服务器、CPU、内存、存储、网络区划、后备电源、操作系统、数据库和容器运行环境是什么？
- 技术影响：部署拓扑、容量规划、故障恢复、备份和性能测试条件。
- 建议证据：资源清单、网络拓扑、安全域说明和环境验收记录。

## 3. 影响详细设计的问题

### TQ-009 移动端宿主环境

- 待确认问题：采用独立应用还是 H5 集成；宿主应用是否提供定位、扫码、拍照、文件上传、消息推送和单点登录桥接能力？
- 技术影响：移动端边界、权限申请、离线提示、兼容性和发布方式。

### TQ-010 流程配置边界

- 待确认问题：核实审批和处置流程需要支持哪些节点、分支、会签、退回、超时和代理规则？运行中实例遇到流程版本更新如何处理？
- 技术影响：流程定义模型、版本策略、实例快照和审计设计。

### TQ-011 预案启动规则

- 待确认问题：同一事件是否允许多预案并行启动，重复点击如何处理，通知人与任务接收人重叠时如何合并，部分下发失败时是否允许继续处置？
- 技术影响：启动幂等、任务快照、并行编排、失败补偿和状态展示。

### TQ-012 打卡防作弊规则

- 待确认问题：允许打卡半径由谁配置，定位权限关闭或定位漂移如何处理，代执行如何授权，二维码是否需要轮换或防复制措施？
- 技术影响：二维码签名、地理围栏、异常标记、证据留存和申诉流程。

### TQ-013 附件和文件服务

- 待确认问题：文件类型、单文件大小、总容量、病毒检测、在线预览、保留期限和敏感文件下载权限如何规定？
- 技术影响：文件存储、上传安全、预览服务、容量和备份设计。

### TQ-014 基础数据初始化

- 待确认问题：预案、人员、区域、楼层、物资、事件类型和模板由谁提供、清洗、确认和签字？是否存在可导入的现有台账？
- 技术影响：数据字典、导入工具、质量校验和项目进度。

### TQ-015 验收和联调环境

- 待确认问题：性能测试环境是否等同生产环境；第三方系统能否提供稳定沙箱；现场联动测试窗口、测试数据和故障注入权限如何安排？
- 技术影响：验证方案可执行性、性能结论可信度和里程碑风险。

### TQ-016 隔离环境软件供应链

- 待确认问题：允许使用的开源许可证范围、离线镜像仓库、依赖制品交付方式和安全扫描工具是什么？
- 技术影响：技术选型、离线安装、许可证合规和漏洞修复流程。

## 4. 后续处置

4. B 根据答复更新技术方案；未答复项采用可替换适配层和明确假设，不形成超出需求的承诺。
