## 3. 建议优先验证事项

1. 统一消息通道的发送、失败、回执和限流行为。
2. 视频平台的设备目录、实时取流及录像回放链路。
3. 人员定位的坐标、楼层、刷新和精度数据。
4. 统一身份认证和组织机构同步。
5. 私有隔离环境中的离线容器化部署。
6. 预案启动主链路的并行处理、幂等、失败恢复和可观测性。

验证结论应作为 G1-04 技术方案、G1-06 项目计划和 G1-07 风险登记册的共同输入。
