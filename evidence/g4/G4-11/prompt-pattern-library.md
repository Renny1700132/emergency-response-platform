# 第四关 Prompt 模式库

| 模式 | 必填信息 | 适用输出 | 防错门禁 |
|---|---|---|---|
| 实现任务 | Task ID、主责/复核、冻结输入、DoD、分支/PR | 代码、测试、RTM、自查 | 先同步与原文日志；只用功能分支；禁止静默改基线 |
| 独立复核 | PR、候选 commit、Issue 范围、验证命令 | PASS / CHANGES_REQUIRED 与证据 | 不以主责身份自批；失败原样记录 |
| 集成准出 | AC 范围、环境边界、覆盖/安全/契约阈值 | 测试执行包与准出结论 | 正式 E2E 与 SIMULATED_EVIDENCE 分列 |
| 故障演练 | 注入点、预期降级、恢复判据、审计字段 | 原始响应、时间线、恢复结果 | 控制指令未知结果不盲重放 |
| 阶段收口 | RTM、任务/PR/commit、Prompt、自查、Review | 双向追踪与关闭判定 | 未获唯一审核人 Approve 时保持 OPEN |

复用原则：Prompt 可调整工作方法，但不得自行改变真实需求、★条款、关键数字、责任边界和验收条件；所有外部课程模拟结果必须显式标注 `SIMULATED_EVIDENCE`。
