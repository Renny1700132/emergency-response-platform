1 引言

1.1 阅读对象
  本手册面向应急指挥员、事件核实人员、现场安保员、任务执行人员、物资保障人
员、值班人员和系统管理员。Web 端用于态势查看、事件核实、预案启动、任务统筹
和业务台账；H5 嵌入既有智慧管理 APP，用于移动事件上报、任务接收反馈、扫码打
                             卡、物资盘点和知识查询。

1.2 系统能做什么
 ·通过 Web/H5 上报、查询和核实事件，并在授权后启动已发布预案；

 ·生成、下发、接收、反馈、催办和完成应急任务，保存附件引用与资源版本；

 ·展示事件、任务、人员、物资、告警和视频引用的态势信息；

 ·管理预案、资源、演练、值班、知识和外部接口状态；

 ·通过统一中台完成身份、权限和文件能力适配，并保留 traceId、审计与幂等记录；

 ·在外部接口超时或失败时显示降级状态，门禁控制失败时转人工处置且禁止自动重
  放。


1.3 当前边界
当前课程候选已经实现 MVP 核心链路及工作台。截图中的橙色“演示数据”标识代表课
 程展示模式，不是甲方实时数据。视频、消息、定位、GIS、安防和信息发布六类甲
 方真实系统仍为 REAL_WORLD_DEFERRED；不得用演示状态判断生产接口已经联
  通。生产身份必须使用统一中台 Bearer 令牌，开发身份头只允许在开发模式显式开
                                           启。

2 快速开始

2.1 登录与入口
 ·在既有智慧管理门户完成登录，由门户向系统传递 Bearer 令牌。

 ·打开 Web 根路径，系统进入 /web/overview；移动端从宿主 APP 打开 /h5/events。

 ·未登录时系统转到“需要登录”；已登录但缺少页面权限时转到“无访问权限”。

 ·登录成功后，右上角显示统一中台返回的显示名；演示模式会额外显示“演示数
  据”。

4 事件上报与核实

4.1 上报事件
 进入“事件管理”，点击“上报事件”，填写事件类型代码、发生时间、标题和描述。
Web 端填写已有文件 ID；H5 可调用中台预签名能力拍照或选择附件。提交成功后系
统刷新服务端状态并显示事件编号。重复提交时应复用幂等键，禁止反复点击形成重
                                      复事件。

4.2 核实事件
具备 incident:verify 的人员展开“核实/启动处置”，选择“确认事件”或“驳回”，填写核实
 说明后提交。页面使用资源版本防止并发覆盖；遇到 409 时重新加载最新状态再决
                                      定，不得直接重复原请求。

4.3 启动预案
 仅对已确认事件输入已发布的预案版本 ID，并填写启动说明。系统按该版本形成快
照、任务和消息待发送记录。消息失败不会回滚已提交的业务任务，而会显示待人工
           复核；不得把“请求已接收”误认为所有外部通道都已送达。

5 任务接收、反馈与完成

5.1 接收任务
在 H5“我的任务”查看授权范围内任务。点击“接收任务”后，系统提交当前资源版本；
成功后状态从待接收进入已接收。若任务已被其他终端处理，页面显示冲突并要求刷
                                       新。

5.2 反馈进度
展开“提交反馈”，填写文字、0—100 的进度和附件。附件只保存中台文件引用，不在
  本系统复制文件内容。网络失败时保留输入内容并重试；若显示 traceId，应连同
                            traceId 和发生时间交给运维。

5.3 催办、完成与临时任务
指挥员可在 Web 端催办或创建临时任务；执行人完成前应确认反馈材料齐全。完成操
作属于状态变更，不能以浏览器返回撤销；确需更正时由授权人员依据审计记录重新
                                     处置。

8 演示模式与正式模式
演示模式通过 npm run demo --prefix frontend 启动，页面显示“演示数据”，用于课程讲
解和界面熟悉；数据保存在浏览器会话中，不构成正式业务记录。正式模式必须连接
 统一中台和 PostgreSQL，由正式 API Client 读取授权数据。发现页面含“演示数据”
         时，禁止将截图用于证明甲方接口、生产数据或实时联动已经通过。

                      表 10-1 术语与定义

术语                             含义

事件                             需要核实、处置和关闭的应急事实记录
