# 过程日志目录

- `prompts/`：按日期追加的 AI 任务日志；每项任务至少完整保存 `USER_PROMPT_RAW` 与 `AGENT_FINAL_OUTPUT_RAW`。
- `raw/<tool>/`：工具可真实导出时保存的原始会话/运行记录。
- `reviews/`：人工评审与自检记录。
- `meetings/`：站会、评审会、澄清会与模拟答辩记录。
- `failures/`：AI 翻车、检查失败与根因分析。

所有记录以真实性和时序可追溯为先。Prompt 摘要不能替代原文；不保存隐藏思维链、内部推理、不可见系统消息或无法真实取得的内容。补录必须显式标记，不得删除失败或弃用记录。
